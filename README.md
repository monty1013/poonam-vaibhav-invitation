# Poonam & Vaibhav Wedding Invitation

A mobile-first, static wedding invitation website. No build tools or paid services are required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Safari, or Firefox.
3. An internet connection is needed for the Google Fonts and remote placeholder photos.

## Personalize before sharing
- Edit `index.html` to update the wording and add/remove pre-wedding events.
- Replace the three gallery image URLs in `styles.css` with your own photos.
- Replace the hero and venue photo URLs in `styles.css` with suitable images.
- Event dates and times are intentionally marked as not yet announced.
- The Maps button searches for “Village Nog, Bilaspur, Himachal Pradesh”; it is not an exact verified pin.
- Music is optional. Add a properly licensed MP3 named `music.mp3` in this folder. Browsers require a user click before playing audio.
- RSVP is not included, as requested.

## Publish free using GitHub Pages
1. Sign in or create a GitHub account.
2. Create a **public** repository, e.g. `poonam-vaibhav-invitation`.
3. Upload `index.html`, `styles.css`, `script.js`, and optionally `music.mp3` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**; choose `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to finish publishing. The public URL appears in Settings → Pages and usually looks like `https://YOUR-USERNAME.github.io/poonam-vaibhav-invitation/`.
7. Open the URL on a phone and test the navigation, map search, music control and share button before forwarding it to guests.

## Important
The event names are sample placeholders, not confirmed programme details. Confirm the final schedule and exact venue pin before publishing. External images and Google Fonts need internet access. This package does not upload or publish anything by itself.
